# MC-Monitor

Веб-приложение для мониторинга серверов Minecraft, написанное на чистом PHP с использованием ООП.

## 🛠 Стек технологий
- **Backend:** PHP 8.4 (ООП, PDO, Namespaces)
- **Database:** MySQL
- **API:** `lukasss93/minecraft-server-status` (через Composer)
- **Frontend:** HTML5, CSS3 (Custom UI, 3D-анимации, Grid/Flexbox)

## ✨ Функционал
- Отображение реального онлайна серверов, версии, пинга и иконки.
- Очистка MOTD от цветовых кодов Minecraft.
- Панель администратора с авторизацией (сессии).
- Добавление и удаление серверов (CRUD).
- Выделение VIP-серверов (кастомный CSS).
- Адаптивный дизайн для мобильных устройств.

## 🚀 Установка
1. Клонируйте репозиторий: `git clone ...`
2. Установите зависимости: `composer install`
3. Создайте `config.php` в корне по примеру `config.example.php`
4. Импортируйте структуру БД (таблица `servers`).
5. Запустите локальный сервер (OpenServer/XAMPP).
